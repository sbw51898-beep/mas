# MAS 正确性治理论文重构设计

## 1. 目标与读者

本次工作不是追加一份按实验日期排列的报告，而是把现有论文重构为一篇以“多智能体最终决策正确性”为核心的问题驱动论文。主要读者是指导教师和了解大模型但不熟悉本项目实现细节的研究人员。新版本另存，不覆盖 2026-08-05 的原论文与脚注版。

## 2. 核心论点

多智能体系统的正确性不能仅用“是否形成共识”或“最终披露率是否达到 100%”判断。私有信息从产生最终答案要依次经过公开、读取、解释和行动四个环节；任一环节失效都可能导致错误共识。因此，治理体系应先捕捉错误所在环节，再选择对应干预，并用最终正确率验证干预效果。

全局 Reveal-All 仅作为信息可得性上限和诊断对照，不作为论文的主要贡献。现有结果中，官方兼容的第一轮全局 Reveal-All 在 ID1-ID3 上达到 30/30；但旧的逐步式 fixed-reveal-all 即使最终原子披露率为 100%，ID2 仍仅有 6/10。该差异用于说明“最终全部出现”不等于“及时、正确地使用”。

## 3. 新研究问题

- RQ1：在分布式私有信息任务中，多智能体会出现哪些可观测的错误现象？
- RQ2：哪些信息处理环节导致最终答案错误，分别可以用哪些指标捕捉？
- RQ3：针对不同错误环节的干预能否改善最终正确率？
- RQ4：更换执行框架和大模型后，HiddenBench 原文的主要结论是否仍成立；若数值不同，差异可能来自哪里？

## 4. 论文结构

### 摘要

用 6-7 句话依次说明：MAS 正确性问题、已有工作缺口、错误链路框架、MAF+DeepSeek 复现与治理方法、主要实验结果、结论边界。

### 1 引言

从“共识不等于正确”切入，说明本文目标不是证明全披露更好，而是解释错误如何发生、如何被观测以及如何干预。提出四个研究问题和本文贡献。

### 2 多智能体错误现象与已有研究

按问题链路组织，而非按论文列表堆叠：

1. 结果层：错误答案、错误共识、理由与投票不一致。
2. 信息公开层：私有事实未披露或披露过晚。
3. 信息利用层：事实已经出现但被忽略、弱化或未进入推理链。
4. 解释层：正确证据被错误解释，或与候选方案错误绑定。
5. 协调层：过早收敛、从众和发言机会分配失衡。

在各小节中对应 Hidden Profile、HiddenBench、MAST、多智能体辩论、发言调度与 MAF；所有来源按正文首次出现顺序使用真实 Word 脚注。

### 3 正确性治理体系

先给出完整过程：任务与私有事实分配 -> 多智能体讨论 -> 原子事实审计 -> 证据利用与解释检查 -> 投票与错误共识检测 -> 选择干预 -> 再评估最终正确率。

用一张核心矩阵明确对应关系：

| 错误环节 | 可观测现象 | 主要观测点 | 对应干预 |
|---|---|---|---|
| 公开 | 私有事实没有进入公共讨论 | 原子披露率、首次披露轮次、所有者披露情况 | 结构化交换、全局 Reveal-All |
| 读取/利用 | 信息出现但没有影响判断 | 后续引用、立场变化、投票前证据覆盖 | 引用证据要求、缺失证据提醒 |
| 解释 | 事实存在但含义理解错误 | 理由与事实一致性、选项-证据映射 | 反思、冲突核验、重新解释 |
| 协调 | 过早收敛或发言失衡 | 发言分布、共识形成轮次、异议消失 | 动态发言、保留异议、延迟表决 |
| 决策 | 理由与投票不一致或错误共识 | 个体票、最终多数、理由-票一致性 | 异常投票复审、二次投票 |

### 4 已有内容、本文改进与原创边界

明确区分三类内容：

- 已有研究：HiddenBench 的任务、官方 GPT-4.1 数据与 Reveal-All 对照；MAST 的失败模式；MAF 的 Agent/模型执行能力。
- 本文实现与改进：在 MAF 上复现 HiddenBench；构造原子事实审计；比较固定、结构化和同预算动态发言；逐运行映射错误环节；形成观测-干预闭环。
- 不能声称原创：Hidden Profile 范式、Reveal-All 思路、MAST 分类和 Microsoft Agent Framework 本身。

动态选择器是项目代码中的外部集中式调度器，不是 MAF 原生群聊能力；Codex 盲审是模型辅助复核，不是人工金标准。

### 5 实验设置与对标方式

解释 ID1-ID3 的选择依据：它们是官方公开了 GPT-4.1 基线和 Reveal-All 结果、可以逐题对表的三个短任务；三题共享场景与候选项，只改变决定正确答案的私有事实链，便于控制背景并观察错误位置差异。明确本文没有覆盖全部 65 题，因此结论只适用于三个短任务。

对标分为两层：

1. 跨实现复现：官方 GPT-4.1+作者模拟器 vs DeepSeek+MAF，判断结论方向是否一致。
2. 本地机制比较：相同任务、模型和预算下比较不同协议，避免把模型、框架或发言次数混作治理效果。

### 6 实验结果与归因分析

结果按问题而非日期展开：

1. 原文与本地复现：官方部分信息基线 ID1-ID3 为 11/30、4/30、6/30；本地 fixed-60 为 10/10、0/10、7/10。方向上均存在分布式信息下的失败，但具体数值不一致。
2. 差异归因：只能提出候选解释，包括模型差异、框架/消息组织差异、协议与预算差异、生成随机性；现有设计同时改变模型和框架，不能把差异单独归因给其中一个变量。
3. 信息时序：官方兼容第一轮全局 Reveal-All 为 30/30；逐步 fixed-reveal-all 总体为 26/30，且 ID2 为 6/10，说明时机和利用过程重要。
4. 发言调度：fixed-60 为 17/30，dynamic-60 为 21/30，McNemar p=0.125；只能报告方向性提升，不能声称统计显著优越。
5. 结构化讨论：fixed-12 为 20/30，structured-12 为 24/30，p=0.388；同样不能声称显著提升。
6. 错误链路证据：FM-2.4 有确认案例；FM-2.5 仅是需要人工因果编码的候选；FM-2.6 未确认。不得把后两项写成已证实结论。

### 7 结论与展望

结论聚焦三点：错误可沿公开、利用、解释和决策链路定位；完整性、时序和正确使用共同影响结果；当前动态与结构化干预有方向性改善但证据不足。展望提出最关键的解耦实验：MAF+GPT-4.1 与原模拟器+DeepSeek，以拆分模型和框架效应；随后扩展至更多官方任务和人工双盲编码。

## 6. 验收标准

1. 论文主结论不再是“全披露更好”，而是正确性治理与错误链路定位。
2. 每种错误现象都有因素、观测点和对应干预。
3. 原文已有内容、本项目实现和本文可主张的改进清楚分开。
4. 原论文与本地复现逐题对比，并明确不能完成单因素归因。
5. 三题选择理由、外推边界和统计不显著结果写清楚。
6. 数据与现有证据快照一致，不增加没有实验支持的结论。
7. 脚注、参考文献、表格、图和附录完整，逐页无裁切、重叠或断裂。
