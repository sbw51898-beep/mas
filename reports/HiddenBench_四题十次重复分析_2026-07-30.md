# HiddenBench 四题十次重复、AI 披露与等预算动态发言分析

## 实验边界

- 任务：HiddenBench ID 1、5、7、25。
- 条件：固定 A-B-C-D 轮转、内容感知动态发言。
- 重复：每个“题目×条件”10次，共80个 run。
- 预算：每次60条公开发言，每名 Agent 恰好15次。
- 配对：同题同次重复使用相同种子、相同私有信息分配和相同模型参数。
- 模型：DeepSeek V4 Flash，temperature=0，thinking=disabled。
- 动态选择器：五因子闭式分数，不调用 LLM，也不读取标准答案。

这是四道代表题的描述性实验，不代表 HiddenBench 65题总体。

## 主要结果

| ID | 固定多数正确 | 动态多数正确 | 固定错误共识 | 动态错误共识 | 固定/动态 AI 披露率 |
|---:|---:|---:|---:|---:|---:|
| 1 | 10/10 | 6/10 | 0/10 | 4/10 | 90.0% / 85.0% |
| 5 | 0/10 | 0/10 | 10/10 | 10/10 | 2.5% / 0.0% |
| 7 | 2/10 | 0/10 | 8/10 | 9/10 | 0.0% / 0.0% |
| 25 | 8/10 | 8/10 | 2/10 | 1/10 | 67.5% / 67.5% |

40个固定 run 中，20个多数正确、20个错误共识；40个动态 run 中，
14个多数正确、24个错误共识。动态机制在等额60次发言预算下没有优于
固定轮转，ID 1 和 ID 7 反而下降，ID 25 持平。因此当前证据不支持
“内容感知动态发言必然改善治理”。

## 稳定性

ID 5 最稳定地失败。固定轮转平均在第7.2条发言形成稳定共识，之后平均
仍有48.8条消息，但10次全部形成错误共识。这说明“很早达成一致”和
“后续不断重复确认”都不能作为正确性的替代指标。

本次另行记录：

- 首次共识出现的发言序号；
- 首次稳定共识的发言序号；
- 共识翻转次数；
- 稳定共识后仍继续的消息数；
- 重复确认次数。

保留15轮是为了与 HiddenBench 官方协议可比，并保证固定/动态机制的
发言预算一致。早停可以作为新的治理干预另做实验，不能事后截断本轮
基线。

## AI 披露审计

AI 对每个 run 的四条私有信息逐项判断，必须返回所有者消息 ID、消息中
的连续原文引句和理由。程序验证说话者、消息 ID 和引句；证据无效时最多
修复一次。披露率由程序按“已披露条数÷4”计算，不使用模型自报百分比。

80个 run 产生80份有效审计，实际发送84次审计请求，其中4次为格式或
证据修复。AI 与 `lexical-semantic-v2` 透明规则在320个逐事实判断上
有84次分歧，一致率73.75%。55次分歧集中于 ID 7：该题一条私有信息
包含多项 RFP 条款，规则命中部分原子条款就会计为披露，而 AI 更倾向
要求完整决策含义进入公共讨论。这是计量单位和口径差异，不能挑选一个
更有利的数字。

## 机制解释

- ID 1：披露较高仍可能错误，说明披露不是充分条件。
- ID 5：披露接近于零，两种机制均10/10错误共识，主要表现为信息未披露
  和错误锚点反复强化。
- ID 7：此前单次 run 中，agent-b 已明确披露 Cape 在 b/f/g/h 上失败，
  下一条却立即忽略该反证并继续支持 Cape，是“披露不等于利用”的清晰
  证据。
- ID 25：固定与动态均8/10正确，动态减少一个错误共识，但没有提高多数
  正确率。

## 与官方 GPT-4.1 的逐题关系

官方公开结果包显示四题 Hidden 讨论后多数正确率分别为：

- ID 1：50%；
- ID 5：0%；
- ID 7：50%；
- ID 25：50%。

最一致的现象是 ID 5：官方 GPT-4.1、本实验固定轮转和动态机制的讨论后
多数正确率都是0%，而官方 Full Profile 为100%。其他三题数值随模型和
编排明显变化。官方结果使用 GPT-4.1 和作者自定义 Python 模拟器；本实验
使用 DeepSeek V4 Flash 和 Microsoft Agent Framework，故只作描述性
对照，不把差值单独归因于框架。
